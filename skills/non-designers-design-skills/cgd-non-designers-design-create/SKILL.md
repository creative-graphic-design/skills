# Create a design

Make the reader's intended first impression, reading order, and next action visible in the layout. Apply the principles to the user's medium and existing visual identity.

## Establish the brief

Use the supplied content, audience, purpose, dimensions, medium, and brand constraints. Inspect an existing artifact before revising it. Resolve missing details only when they change the design substantially; otherwise state the assumption and proceed. Preserve required wording, contact details, and functional behavior.

Deliver the format the user requested. A request for a layout specification needs positions and styles; a request for an artifact needs an artifact. Use the available project tools and assets. Do not select a new application or output format just to demonstrate the principles.

## Inspect the visual example

Before composing a layout, open the [original layout comparison](references/layout-comparison.png) with an image-capable tool. Compare the panels' reading order, distances within and between groups, shared edges, and repeated treatments. Name the relationship you will transfer to the brief; do not copy the example's dimensions or visual style automatically. If image inspection is unavailable, state that limitation instead of claiming to have examined the example. The [editable SVG](references/layout-comparison.svg) is its source.

## Compose the page

1. Choose the focal point from the communication goal. An event may lead with its subject and date; a service listing may lead with the service. The organization name is not automatically the most important element. Sketch the intended reading order before styling individual pieces.
2. Group related information. Keep a heading closer to the content it introduces than to the preceding block; keep a caption with its image and contact details with the action they support. Make within-group gaps smaller than between-group gaps. Use empty space to distinguish relationships rather than filling every corner.
3. Establish alignment anchors. Connect text, images, rules, and distant groups through shared edges or baselines. A strong existing photo edge can anchor the page. Centered composition can suit a formal brief; use it deliberately, and avoid unrelated alignment changes within one group.
4. Repeat a small visual vocabulary. Reuse heading treatments, spacing relationships, accent colors, rules, and image treatments across related sections or pages. Strengthen an existing repeated element before adding decoration. Repetition should make related content recognizable without competing with the focal point.
5. Make role differences visible through contrast. Contrast scale, weight, shape, spacing, or color enough to distinguish the headline, supporting text, and details. If two elements have the same role, unify them. If their roles differ, make the distinction intentional. Making everything large and bold removes hierarchy.

## Choose typography

Start with the available type family and its real weights and styles. Add another family only when it contributes a distinguishable role. Compare letterform construction, not just font names: serif shape, thick-to-thin stroke change, stroke stress, width, and x-height determine whether two faces look confusingly similar.

Use the book's six contrast dimensions as choices, not a requirement to apply all six:

| Dimension | Design decision                                                                                                                                                                         |
| --------- | --------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| Size      | Separate information levels with a visible change; keep necessary details readable at the intended viewing size.                                                                        |
| Weight    | Use a real heavier or lighter cut to reinforce the same hierarchy as size. Watch for a small bold element competing with a large light headline.                                        |
| Structure | Pair clearly different constructions, such as an oldstyle serif and a monoweight sans, or use distinct weights within one family. Merely switching between similar serifs adds noise.   |
| Form      | Use roman versus italic or mixed case versus capitals for a reason. Two flowing scripts, or a script and similar italic, may compete. Reserve difficult letterforms for short passages. |
| Direction | Contrast a horizontal heading with a vertical column of text. Rotate text only when the direction contributes to the message, not to fill an empty corner.                              |
| Color     | Consider both hue and the light or dark texture made by weight, density, line spacing, and letter spacing. A monochrome page can still have strong typographic contrast.                |

A restrained, single-family composition can be the right answer. Avoid turning contrast into a demand for extra fonts or decoration. Check display faces with fine hairlines at the actual output size; script and decorative faces usually need short text and enough room. Set body text for sustained reading through suitable line length, spacing, and weight.

The book's categories describe Latin letterforms. For other writing systems, inspect the actual glyphs, available weights, and mixed-script balance instead of imposing Latin-specific rules about capitals or italics.

## Choose color

Start from the brand, an important image, or the intended mood. Choose a relationship that serves the piece: one hue with tints and shades, neighboring hues for continuity, or complementary, split-complementary, or triadic hues for more separation. Give colors roles such as background, text, and accent rather than equal visual weight by default.

Check light-dark separation as well as hue. Different hues with similar values can merge in grayscale or become difficult to read when adjacent. A warm accent can command attention with a small area; judge its actual effect against the background. Keep the primary emphasis recognizable when color is removed.

Use screen color for screen artifacts. For print, follow the printer's requested color space and output specifications; do not assume a monitor preview predicts ink on paper. Avoid repeated color-space conversions.

## Adapt to the medium

- For a flyer, poster, ad, or slide, make the main message easy to find at its expected viewing distance, then group supporting information and the next action.
- For business cards and stationery, carry the same identity across pieces. Keep contact information usable and leave letterhead space for the letter itself.
- For newsletters and multipage documents, repeat columns, headings, captions, and spacing. Let a feature differ against that stable pattern.
- For folded material, plan the panel reading order and keep essential text clear of folds and gutters. Verify dimensions against the production brief.
- For web pages, preserve navigation and component consistency, readable line lengths, and layout at the requested viewport sizes. Use the project's current layout methods.

Treat the book's particular font bans, point sizes, postal dimensions, and historical web techniques as examples of their original context, not universal production requirements.

## Check and deliver

Inspect the rendered result when tooling permits, at the intended size and as a reduced preview. Trace the focal point and reading order, inspect the grouping and alignment, compare repeated treatments, and check that contrast still distinguishes roles. Use a grayscale preview when hierarchy depends on hue. Check clipping, overlaps, missing text, and readability against the actual brief. If only source or a specification was inspected, say so instead of claiming visual verification.

Return the artifact or actionable layout specification with a brief explanation of the decisions that matter for this brief. When revising, address the relevant defects without changing an established identity merely to demonstrate a principle.

## Source
